개념 비유 7가지벽지 공장 현장에 빗대어

1. 챗봇과 AI 에이전트 챗봇은 상담 창구입니다. 답은 주지만 엑셀에 옮기는 건 내 몫입니다. 에이전트는 현장에 투입된 작업자입니다. 내 폴더의 파일을 열고, 만들고, 실행하고, 결과를 보고합니다.
생각해 보기 엑셀 파일 10개를 합쳐 달라고 했을 때, 챗봇과 에이전트의 결과물은 각각 무엇일까요?
2. 필요한 역량이 바뀌었다 예전에는 용접기를 다루는 기능공(문법 암기)이 필요했습니다. 지금은 도면을 정확히 그리고 완성품을 검수하는 사람(업무 설명과 검증)이 더 중요합니다.
생각해 보기 우리 부서 업무를 가장 정확히 설명할 수 있는 사람은 누구일까요? — 바로 나입니다.
3. 프롬프트는 작업지시서 작업지시서에 품목·수량·납기가 빠지면 현장이 멈춥니다. 프롬프트도 목적·재료·결과 모양·금지사항 4칸을 채워야 원하는 결과가 나옵니다.
4. 한 번에 하나씩 온도·속도·텐션을 한꺼번에 바꾸면 불량이 나도 원인을 모릅니다. AI에게도 수정을 하나씩 시키고, 잘되면 저장합니다.
생각해 보기 ‘차트 추가하고 색도 바꾸고 필터도 넣어줘’를 세 번의 요청으로 나눠 보세요.
5. 환각과 검증 초품 검사처럼, 첫 롤을 뜯어보지 않고 양산에 들어가지 않습니다. AI 결과도 원본 엑셀과 숫자 3개를 대조한 뒤 씁니다.
생각해 보기 AI가 ‘합계 12,250m’라고 했습니다. 어떻게 확인할까요?
6. 되돌리기는 안전장치 세이브 카메라로 작업할 때마다 사진을 찍어 둡니다. AI가 잘 되던 걸 망가뜨려도 사진 찍은 시점으로 돌아갑니다.
7. 데이터 신호등 초록은 바로 넣어도 됩니다(거래처명 없는 MES 가동·불량). 노랑은 가린 뒤 넣습니다(거래처 주문, 담당자 연락처). 빨강은 넣지 않습니다(급여·인사평가, 단가·원가, 원청 시스템 자료).

1교시 · 바이브코딩이란약 50분

한 문장으로 코드를 배우는 게 아니라, 내 업무를 말로 설명해서 도구를 얻는 법을 배웁니다.

1. 바이브코딩은 정확히 무엇인가

  • 정의 — 만들고 싶은 것을 일상 언어로 설명하면 AI가 코드를 작성·실행·수정합니다. 사람은 결과를 보고 “여기는 이렇게 바꿔줘”라고 방향을 잡습니다.
  • 용어의 유래 — 2025년 2월 안드레이 카파시(전 테슬라 AI 총괄, OpenAI 창립 멤버)가 “코드는 잊고 분위기(vibe)에 몸을 맡긴다”고 표현한 데서 시작됐습니다.
  • 오해 바로잡기 — 대충 만드는 것이 아닙니다. 무엇을·왜·어떤 순서로 하는지 아는 업무 담당자가 가장 잘할 수 있는 방식입니다.

2. 왜 지금인가

  • 답만 하던 챗봇에서, 내 PC의 파일을 읽고 만들고 실행까지 하는 ‘AI 에이전트’(클로·코덱스·안티) 시대로 넘어왔습니다.
  • “개발팀에 요청 → 일정 대기 → 외주”였던 작은 업무 도구를, 현업 담당자가 반나절에 직접 만들 수 있습니다.
  • 필요한 역량이 ‘문법 암기’에서 ‘업무를 정확히 설명하는 힘, 결과를 검증하는 눈’으로 바뀌었습니다.

# 월간 생산 보고서 만들기

data 폴더의 생산실적 엑셀 하나를 읽어, 호기별 불량률 보고서를 HTML 한 파일로 만든다.

## 입력
- 엑셀 파일 이름: $ARGUMENTS
- 파일 이름이 비어 있으면 data 폴더의 엑셀 목록을 보여 주고 어느 파일인지 먼저 묻는다.
- 시트 이름은 `생산실적`, 컬럼은 `생산일자, 제품코드, 호기, 생산량(m), 불량량(m), 가동시간(분), 오븐온도(℃)`.

## 순서
1. `data/` 폴더에서 엑셀을 읽는다. 원본 엑셀은 절대 수정하지 않는다.
2. 생산일자에서 연·월을 알아낸다(예: 2026-10).
3. 호기별로 계산한다.
   - 생산량 합계, 불량량 합계
   - 불량률(%) = 불량량 합계 ÷ 생산량 합계 × 100, 소수 첫째 자리까지
   - 날짜별 불량률의 평균을 내지 않는다. 반드시 합계끼리 나눈다.
4. 전체(모든 호기) 생산량·불량량·불량률도 같은 식으로 계산한다.
5. `output/월간보고_연도-월.html` 로 저장한다(예: `output/월간보고_2026-10.html`). 같은 이름이 있으면 덮어쓰기 전에 묻는다.

## 보고서 모양
- 맨 위: 제목 `㈜금진 월간 생산 보고 · 연도년 월월`, 그 아래 작은 글씨로 `교육용 가상 데이터`
- 요약 3줄: ① 전체 생산량과 불량률 ② 불량률이 가장 높은 호기와 수치 ③ 확인이 필요한 점 한 가지
- 호기별 불량률 막대 차트 1개. 불량률이 가장 높은 호기의 막대만 주황색(#c96442), 나머지는 남색(#1d3a7a)
- 호기별 표: 호기, 생산량(m), 불량량(m), 불량률(%). 맨 아래에 전체 행
- 색은 베이지 배경(#f6f1e7)과 남색 글자. 외부 인터넷 자료(글꼴·라이브러리)를 불러오지 않는 한 파일

## 마친 뒤 보고
- 만든 파일 위치
- 원본 대조용 숫자 3개: 행 수, 전체 생산량 합계, 전체 불량량 합계
- "엑셀에서 이 3개를 직접 확인해 주세요"라고 안내한다.

## 하지 않는 것
- data 폴더의 파일을 고치거나 지우지 않는다.
- 엑셀에 없는 숫자를 지어내지 않는다. 값이 비었거나 이상하면 계산에서 빼고, 뺀 건수를 보고서 맨 아래에 적는다.
내 SKILL.md에 name·description이 있고, 본문에 불량률 계산식과 output 저장 위치가 적혀 있습니다.
계산식이나 저장 위치가 빠졌다면 Claude Code 창에서 “스킬에 ○○ 규칙을 추가해줘”라고 보내세요. 급하면 정답 예시를 내려받아 같은 위치에 덮어써도 됩니다.

"""날씨 MCP 서버(정답 예시) — 금진 바이브코딩 모듈 5 심화(5-21).

열쇠(API 키)가 필요 없는 공개 날씨 서비스 Open-Meteo(api.open-meteo.com)에서
지금 날씨를 가져온다. Claude Code에 등록하면 "천안 공장 지금 습도 알려줘"처럼 말로 부를 수 있다.

준비:   pip install mcp
등록:   claude mcp add weather -- python mcp/weather_server.py   (gj-report 폴더에서)
"""
import json
import urllib.parse
import urllib.request

from mcp.server.mcpserver import MCPServer

mcp = MCPServer("weather")


@mcp.tool()
def current_weather(latitude: float, longitude: float, place: str = "") -> dict:
    """지금 날씨(기온·습도·강수량·풍속)를 알려준다.

    사용자가 도시 이름만 말하면 그 도시의 위도·경도를 직접 넣어서 부른다.
    예: 천안 36.81, 127.11 / 서울 37.57, 126.98 / 일산 37.66, 126.77
    place에는 사용자가 말한 장소 이름을 그대로 넣는다(결과 표시용).
    """
    query = urllib.parse.urlencode({
        "latitude": latitude,
        "longitude": longitude,
        "current": "temperature_2m,relative_humidity_2m,precipitation,wind_speed_10m",
        "timezone": "Asia/Seoul",
    })
    with urllib.request.urlopen("https://api.open-meteo.com/v1/forecast?" + query, timeout=15) as res:
        now = json.load(res)["current"]
    return {
        "장소": place or f"{latitude}, {longitude}",
        "기준시각": now["time"],
        "기온(℃)": now["temperature_2m"],
        "습도(%)": now["relative_humidity_2m"],
        "강수량(mm)": now["precipitation"],
        "풍속(km/h)": now["wind_speed_10m"],
        "출처": "Open-Meteo (api.open-meteo.com)",
    }


if __name__ == "__main__":
    mcp.run()

"""생산실적 조회 MCP 서버(정답 예시) — 금진 바이브코딩 모듈 5 심화(5-22).

프로젝트 폴더의 data 폴더에 있는 생산실적 엑셀을 읽어 호기별 불량률을 알려준다.
인터넷에 나가지 않고 내 PC 안의 파일만 읽는다. 원본 엑셀은 읽기만 하고 고치지 않는다.

준비:   pip install mcp openpyxl
등록:   claude mcp add mes -- python mcp/excel_server.py   (gj-report 폴더에서)
"""
from pathlib import Path

from openpyxl import load_workbook
from mcp.server.mcpserver import MCPServer

DATA = Path(__file__).resolve().parent.parent / "data"   # gj-report\data
mcp = MCPServer("mes")


def _rows(file: str):
    path = DATA / Path(file).name   # data 폴더 밖의 파일은 열지 않는다
    if not path.exists():
        raise ValueError(f"data 폴더에 {path.name} 파일이 없습니다. list_files로 이름을 확인하세요.")
    ws = load_workbook(path, read_only=True, data_only=True)["생산실적"]
    rows = ws.iter_rows(values_only=True)
    head = next(rows)
    return [dict(zip(head, r)) for r in rows if r and r[0]]


@mcp.tool()
def list_files() -> list[str]:
    """data 폴더에 있는 생산실적 엑셀 파일 이름 목록을 알려준다."""
    return sorted(p.name for p in DATA.glob("*.xlsx"))


@mcp.tool()
def defect_rate(file: str, line: int | None = None) -> dict:
    """생산실적 엑셀 하나로 호기별 생산량·불량량·불량률을 계산한다.

    file: data 폴더의 엑셀 파일 이름(예: mes_sample_oct.xlsx). 몇 월 파일인지 모르면 list_files를 먼저 부른다.
    line: 호기 번호(1·2·3). 비우면 전체 호기와 합계를 모두 돌려준다.
    불량률 = 불량량 합계 ÷ 생산량 합계 × 100, 소수 첫째 자리.
    """
    data = _rows(file)
    result = {"파일": Path(file).name, "행 수": len(data), "호기별": {}}
    for no in sorted({r["호기"] for r in data}):
        if line and no != line:
            continue
        part = [r for r in data if r["호기"] == no]
        made, bad = sum(r["생산량(m)"] for r in part), sum(r["불량량(m)"] for r in part)
        result["호기별"][f"{no}호기"] = {"생산량(m)": made, "불량량(m)": bad, "불량률(%)": round(bad / made * 100, 1)}
    if not line:
        made, bad = sum(r["생산량(m)"] for r in data), sum(r["불량량(m)"] for r in data)
        result["전체"] = {"생산량(m)": made, "불량량(m)": bad, "불량률(%)": round(bad / made * 100, 1)}
    return result


if __name__ == "__main__":
    mcp.run()
