# 실제 화면 캡처 넣는 곳

교안 부록의 '화면 캡처 목록'에 있는 화면 ID 이름으로 PNG를 저장하면(예: `m2-13b.png`),
교안을 열 때 모형 대신 실제 캡처가 자동으로 보입니다. 화면 아래 '모형 보기' 버튼으로 다시 모형을 볼 수 있습니다.

- 계정 메일·개인정보가 보이지 않게 찍습니다.
- 리허설에서 특히 확인할 화면: m2-07(설치), m2-11(Python 설치 첫 화면), m2-13b·m2-14a·m2-14b(Claude Code 첫 실행·권한 창), m1-08a(미리보기 다운로드 메뉴)
- 모듈 5에서 공식 문서에 화면 문구가 없어 모형으로만 그린 화면(리허설에서 꼭 확인): m5-03b(/memory 목록), m5-07b(/ 목록의 스킬 표시), m5-13(claude mcp list 출력), m5-14a(/mcp 메뉴), m5-14b(노션 허용 화면), m5-15(노션 도구 권한 창)
